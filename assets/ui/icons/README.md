# Upgrade icon art

Generated individually with the built-in imagegen tool, using
`references/upgradesimple.png` as a style reference. Each PNG retains its
transparent background. The UI supplies all titles, levels, and prices.

The game loads the 256px `.webp` versions (quality 85, alpha preserved).
The original PNGs are retained as source artwork and are not needed in a release.

## Final prompt template

Use case: stylized-concept. Generate ONE standalone game upgrade icon PNG with a
genuinely transparent background. Subject: {subject}. The supplied image is STYLE
REFERENCE ONLY: match its soft rounded clay-like 3D illustrated icon style, clean
chunky geometry, satin materials, blue/white palette with restrained golden accents,
subtle shading, friendly premium casual football game look. Single centered icon,
fills about 75% of square canvas, readable at 80px. No surrounding card, no UI, no
words, no letters, no numbers, no border, no background scene, no logos. Output only
this individual icon, not a sheet. Asset key: {key}.
